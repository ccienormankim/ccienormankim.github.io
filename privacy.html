inbox-assistant 개인정보처리방침

시행일: 2026년 11월 9일

inbox-assistant(이하 "앱")는 개인이 자신의 PC에서 사용하는 메일 정리 도구입니다. 이 방침은 앱이 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 접근하는 데이터

앱은 Google OAuth 범위 https://www.googleapis.com/auth/gmail.readonly만 요청합니다. 이 권한으로 받은편지함 메일의 제목, 보낸 사람, 수신 시각, 본문, 스레드 식별자를 읽습니다. 앱은 메일을 보내거나 수정하거나 삭제하지 않습니다.

2. 데이터 사용 목적

읽은 데이터는 사용자 본인에게 메일 요약, 우선순위, 할 일, 기한을 보여 주는 목적으로만 사용합니다.

3. 처리와 저장

  • 메일 처리는 사용자의 PC 안에서 이루어지며, 요약에는 같은 PC에서 실행되는 AI 모델을 사용합니다.
  • 저장 전에 전화번호, 이메일 주소, 인증번호 등 형식이 있는 민감정보를 가립니다. 이름, 주소처럼 형식이 없는 정보는 가려지지 않을 수 있습니다.
  • 요약과 마스킹된 본문 일부는 사용자 PC의 로컬 데이터베이스에 저장됩니다.
  • OAuth 인증 정보는 사용자 PC에만 저장됩니다.

4. 공유와 전송

앱은 Google 사용자 데이터를 앱 운영자의 서버나 제3자에게 전송, 공유, 판매하지 않습니다. 광고에 사용하지 않으며, 범용 AI 모델의 학습에 사용하지 않습니다. 네트워크 통신은 Google API 호출에 한정됩니다.

5. Google API 제한적 사용

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

6. 보관과 삭제

데이터는 사용자가 삭제할 때까지 사용자 PC에 보관됩니다. 사용자는 앱의 data 폴더를 삭제해 저장된 데이터와 인증 정보를 지울 수 있고, Google 계정의 타사 액세스 설정에서 앱의 권한을 언제든 해제할 수 있습니다.

7. 문의

이 방침에 대한 문의는 GitHub Issues로 남겨 주세요.

Privacy Policy (English)

Effective date: November 9, 2026

inbox-assistant is a personal email organizer that runs on the owner's own computer.

  • Data accessed: The app requests only the gmail.readonly scope and reads message subject, sender, received time, body, and thread identifiers. It does not send, modify, or delete mail.
  • Use: Data is used only to show the user summaries, priorities, tasks, and due dates of their own mail.
  • Processing and storage: Processing happens on the user's computer with a locally running AI model. Formatted sensitive data is masked before storage. Summaries, masked excerpts, and OAuth credentials are stored only on the user's computer.
  • Sharing: Google user data is not transferred, shared with, or sold to the operator's servers or any third party, is not used for advertising, and is not used to train generalized AI models. Network traffic is limited to Google API calls.
  • Limited Use: Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Retention and deletion: Data stays on the user's computer until the user deletes it. Access can be revoked at any time in the Google Account permissions page.
  • Contact: GitHub Issues.
